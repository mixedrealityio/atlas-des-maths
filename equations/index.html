Dénombrement, probabilités

  • Factorielle, arrangementslistes ordonnées de p éléments distincts
    n! = 1×2×…×n ; A(n,p) = n!/(n−p)!
  • Combinaisonsparties à p éléments d’un ensemble à n éléments
    C(n,p) = n! / (p!(n−p)!)
  • Probabilité d’une réunion
    P(A∪B) = P(A) + P(B) − P(A∩B)
  • Probabilité conditionnelle
    PB(A) = P(A∩B) / P(B)
  • Probabilités totales, BayesAi : partition de l’univers
    P(B) = Σ P(Ai)PAi(B) ; PB(A) = PA(B)P(A)/P(B)
  • Espérance, varianceécart type σ = √V

  • Loi binomiale
    P(X=k) = C(n,k)pk(1−p)n−k ; E = np ; V = np(1−p)
